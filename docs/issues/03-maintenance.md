# 依存関係・API互換性を点検する

## 背景

SDK・モデル仕様の変更に追随し、両OSの導入手順を維持する。
作業用原稿であり、自動実行のスケジュールは設定していない。

## 作業

- 公式資料のモデル名、応答形式、入力制限と実装を照合する。
- openaiの更新候補を検証し、必要ならrequirements.txtを更新する。
- Python対応版、起動手順、Actionsの利用版を確認する。
- 変更に対応するモック試験を追加し、両OSのCIを確認する。
- 再開機能などの機能追加は別Issueにする。

## 受入条件

- [ ] 確認日・公式資料・対象バージョンをPRに記録する
- [ ] API通信なしのテストと公開チェックに合格する
- [ ] 必要に応じREADMEを更新する
- [ ] キー・音声・結果を含めず1課題1PRで提出する
