# Windows/macOSのGUI・起動手順とAPI疎通を検証する

## 背景

会話仕様から再実装した版のため、元コードの動作実績を本版の検証実績としない。

## 手順

- READMEどおり導入し、bat/command/Condaで起動する。
- 日本語・空白のパス、単体、一括、大文字M4A、空フォルダを確認する。
- 処理中の画面応答、開始の二重押し防止、停止と閉じる操作を確認する。
- ffmpegなし、既存出力、書込権限なし、破損音声の表示を確認する。
- API試験は別途明示的に許可を得て、利用者自身のキーと権利のある短い試験音声で実施する。
- 成功、認証失敗、途中失敗・停止、partial保存、一時ファイル削除を確認する。
- キー・音声・結果をリポジトリ、Issue、スクリーンショットに含めない。
